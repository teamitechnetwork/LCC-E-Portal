Build a complete, modern, production-ready **Liberia Christian College (LCC) E-Portal**.

This must be a **real working application**, not a UI prototype. Build the frontend, backend, PostgreSQL database, authentication, role permissions, APIs, and core workflows.

## TECHNOLOGY

Use:

* React + TypeScript
* Node.js + TypeScript
* PostgreSQL
* Prisma ORM
* Tailwind CSS
* REST API
* React Hook Form + Zod
* Lucide icons
* Recharts
* PDF generation
* QR code generation

Use the existing Replit project stack if one is already configured rather than unnecessarily replacing it.

## USER ROLES

Create four secure roles:

1. Student
2. Staff
3. Admin
4. Super Admin

Use server-side role-based permissions. Users must never be able to access unauthorized APIs or pages simply by changing URLs.

---

# MOBILE-FIRST DESIGN — VERY IMPORTANT

The portal must be designed **mobile-first**, not desktop-first.

It must work exceptionally well on:

* Android phones
* iPhones
* Small phones
* Large phones
* Tablets
* Laptops
* Desktop monitors

The mobile experience must feel like a professional mobile application.

### Mobile requirements

* No horizontal scrolling
* No broken tables
* No tiny text
* No overlapping elements
* Touch-friendly buttons and controls
* Minimum comfortable touch targets
* Responsive forms
* Responsive cards
* Responsive charts
* Responsive modals
* Responsive dropdowns
* Responsive tables with horizontal scrolling only inside the table container when absolutely necessary
* Mobile-friendly file uploads
* Mobile-friendly PDF/document viewing
* Sticky mobile navigation where appropriate
* Collapsible sidebar
* Hamburger menu
* Bottom navigation for important student functions where useful

On mobile, prioritize:

**Home | Courses | Results | Fees | More**

The desktop sidebar must automatically transform into a mobile navigation system.

Test the interface at approximately:

**320px, 375px, 390px, 414px, 768px, 1024px, 1440px+**

Do not simply shrink the desktop layout. Reorganize components intelligently for mobile.
